# Remotion — субтитры на видео

## Установка
```bash
cd remotion-subtitles
npm install
```

## Как использовать
1. Положи видео сюда: `public/video.mp4`.
2. Отредактируй `src/captions.json` — список реплик:
   ```json
   [{"text": "Привет!", "start": 0, "end": 1.5}]
   ```
   `start`/`end` — секунды от начала видео.
3. Открыть студию с превью:
   ```bash
   npm start
   ```
4. Отрендерить готовое видео с субтитрами:
   ```bash
   npm run render
   ```
   Результат: `out/video.mp4`.

Длительность композиции подстраивается под длительность `public/video.mp4` автоматически.
Формат кадра — 1080x1920 (вертикальное видео), поменять можно в `src/Root.tsx`.
