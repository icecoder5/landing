# Remotion — субтитры на видео (караоке-стиль)

## Установка
```bash
cd remotion-subtitles
npm install
```

## Как использовать

1. Положи видео сюда: `public/video.mp4`.

2. Получи тайминги слов через Whisper (на своей машине, офлайн):
   ```bash
   whisper video.mp4 --language Russian --model small \
       --word_timestamps True --output_format json
   ```
   Это создаст `video.json` рядом с видео.

3. Сконвертируй его в формат проекта:
   ```bash
   python3 scripts/convert-whisper.py video.json src/captions.json
   ```

   Формат `src/captions.json` — список строк субтитров, у каждой свои слова
   с таймингом (используется для подсветки слова по мере произношения):
   ```json
   [
     {
       "start": 0,
       "end": 2,
       "words": [
         {"word": "Привет", "start": 0, "end": 0.5},
         {"word": "мир", "start": 0.5, "end": 2}
       ]
     }
   ]
   ```

4. Открыть студию с превью:
   ```bash
   npm start
   ```

5. Отрендерить готовое видео с субтитрами:
   ```bash
   npm run render
   ```
   Результат: `out/video.mp4`.

## Стиль субтитров
Настроен в `src/Subtitles.tsx`:
- позиция — внизу кадра;
- крупный жирный текст с чёрной обводкой (читаемо на любом фоне);
- активное слово подсвечивается жёлтым и слегка увеличивается — караоке-эффект.

Цвета, шрифт, позицию и количество слов в строке (`WORDS_PER_LINE` в
`scripts/convert-whisper.py`) можно менять под задачу.

Длительность композиции подстраивается под длительность `public/video.mp4` автоматически.
Формат кадра — 1080x1920 (вертикальное видео), поменять можно в `src/Root.tsx`.
